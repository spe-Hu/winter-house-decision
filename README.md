# 嘉定购房参考地图

本地离线辅助工具，帮助个人快速浏览上海嘉定区各板块二手房小区的地图位置、户型、交通、学区、商业配套等核心选筹信息。

## 快速启动

```bash
# 直接双击 index.html，或在终端执行：
open index.html
```

无需构建工具，无需 Node.js，无后端服务，双击即用（地图切片需联网加载）。

## 核心特性

1. **100% 高德原生底图文字对齐**：
   - 彻底解决大型多期综合体（如中信泰富又一城、盘古天地、华润中央公园）地块及售楼处偏差，图钉圆心与高德底图印刷文字 **0 米误差咬合**；
   - 杜绝大模型猜测推演，全量数据基于高德官方严格住宅 POI（`types=120300`）强校验阻断。
2. **高德官方真彩矢量 + 卫星航拍双底图**：
   - 默认加载高德官方最新全要素矢量标准底图（`style=7`）；
   - 支持右上角控制器一键切换至高德官方真实航拍卫星实景（`style=6` + `style=8` 透明路网），直观查看楼间距与河流水系。
3. **大盘精确拆解与组团选筹对比**：
   - 超级大盘细化拆解（如中信泰富一/二/三期、盘古一/二期、华润一/二期、安亭新镇德绍豪斯与万科莱茵半岛等）；
   - 抽屉内独家上线【🏛️ 期数组团与选筹对比】，深度分析房龄、梯户比、外立面与噪音差异。
4. **专业级两房 / 三房户型档案库**：
   - 摒弃流水账式的临时在售条目，沉淀经典户型谱系，支持两房/三房分类快速切换；
   - **高亮得房率**：金色徽章醒目对比建筑面积与套内实得面积；
   - **客观优缺点**：客观展示空间优势与避坑痛点；
   - **高清户型图**：本地静态离线秒开，支持点击全屏灯箱（Lightbox）缩放。

## 交付前自动化全量测试与质量门禁 (Pre-Delivery Workflow)

在每次代码修改、功能迭代或数据更新后，**必须**运行交付前全量质量工作流脚本：

```bash
./scripts/run_delivery_workflow.sh
```

该工作流会自动按序执行 6 大质量关卡，耗时约 16 秒：
1. **户型图真值元数据库校验与生成**（`build_floorplan_catalog.py`，OCR 物理房间标尺比对）
2. **全量 35 个小区 78 套户型实证断言**（`refine_layouts_data.py`，物理房间真值对齐，绝无串图）
3. **2026 官方权威双学区真值库对齐**（`align_school_ground_truth.py`，基于官方文字版与独家学区图 100% 对齐）
4. **多源立体交通噪音几何拓扑计算**（`spatial_noise_engine.py`，11号线地上高架/胜辛路主干道立体噪音测算）
5. **零依赖离线数据集打包编译**（`build_dataset.py`，编译生成 `data/dataset.js`）
6. **端到端全场景自动化回归测试集**（`verify_all_regression.py`，代码安全+学区真值硬断言+Playwright 9 大场景自动化测试）

任何一项测试不通过将立即熔断。全绿后系统才处于可信交付状态。详见 [docs/pre_delivery_workflow_sop.md](file:///Users/wentao.hu/Documents/HomePage/00-projects/00-doing/买房参考软件/docs/pre_delivery_workflow_sop.md) 与 [docs/school_district_ground_truth_sop.md](file:///Users/wentao.hu/Documents/HomePage/00-projects/00-doing/买房参考软件/docs/school_district_ground_truth_sop.md)。
