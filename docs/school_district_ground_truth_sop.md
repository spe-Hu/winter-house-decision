## 三、嘉定核心板块 2026 学区招生地段规则

### 1. 嘉定新城核心区（马陆镇）
- **交大附中附属嘉定德富中学**：“胜辛路以东、绕城高速（G1503）以南、沪宜公路以西、伊宁路以北地区，以及洪德路35弄、38弄”；
- **交大附中附属嘉定洪德中学**：“沈海高速（G15）以东、绕城高速（G1503）以南、胜辛路以西、伊宁路以北地区”；
- **普通小学白银路分校**：“永盛路以西、塔秀路以北、沈海高速以东、绕城高速以南地区”；
- **嘉定新城普通第二小学**：“沪宜公路以西、伊宁路以北、沈海高速以东、塔秀路以南地区”；
- **德富路小学**：“沪宜公路以西、塔秀路以北、永盛路以东、绕城高速以南地区”。

### 2. 南翔镇（学籍直升制）
南翔镇公办初中采用“学籍对口入学”，接收对应小学五年级毕业生直升：
- **留云小学** -> **上海大学附属嘉定留云中学**（隽翔、留云、嘉绣、翔北社区等）
- **古猗小学** -> **上海大学附属嘉定留云中学（古猗校区）**（丰翔、芳林、瑞林、宝翔社区等）
- **上师大嘉定小学** -> **上海师范大学附属嘉定中学**（永翔、银翔、金通、劳动街社区等）
- **南翔小学** -> **上海市嘉定区南翔中学**（新翔、德华、虹翔、德园、清猗社区等）
- **世外云翔小学** -> **世外教育附属嘉定云翔中学**（云翔拓展大居等）

## 四、后续新增小区学区真值验证规范

未来在嘉定区录入任何新小区时，**严禁人工凭主观经验填写学区**，必须严格遵循以下 SOP：

1. **定位四至坐标或居委会归属**：
   查询新小区的门牌地址及所属居委会（可利用高德逆地理编码接口）；
2. **检索官方真值库**：
   在 `data/school_ground_truth.json` 中比对四至道路边界或社区居委会名单；
3. **运行交付前自动化流水线**：
   ```bash
   ./scripts/run_delivery_workflow.sh
   ```
   流水线中的 `scripts/align_school_ground_truth.py` 与 `scripts/verify_all_regression.py` 将自动执行真值名录与硬断言校验，若发现任何未录入官方真值库的学校名称或逻辑错配，将立即熔断拦截。
