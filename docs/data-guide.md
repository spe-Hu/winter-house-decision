# 嘉定购房参考地图 — 数据结构与选筹规范指南

## 1. 数据真相源

项目数据的**唯一真相源文件**为：
`data/jiading_xiaoqu.json`

该文件维护全量 140 个核心主力小区及分期组团的完备档案（覆盖嘉定新城、南翔、江桥、安亭、嘉定老城、菊园新区、马陆、徐行、真新/丰庄、外冈 10 大核心板块，包含 288 套两房/三房独立实测户型档案）。

## 2. 小区模型（Community Schema）

每个小区对象包含以下标准字段：

| 字段 | 类型 | 说明 | 示例 |
| :--- | :--- | :--- | :--- |
| `id` | string | 唯一编码（以 5011 开头） | `"5011000010001"` |

| `parent_cluster` | string | 所属超级大盘归属（用于期数横向对比） | `"中信泰富又一城"` |
| `phase_info` | string | 期数核心特征摘要 | `"一期 (双丁路1500号，2010年建，地铁口230m)"` |
| `plate` | string | 所属板块（嘉定新城/南翔/江桥/真新/马陆/安亭/菊园新区/嘉定老城/徐行/外冈） | `"嘉定新城"` / `"南翔"` / `"真新"` 等 |
| `district` | string | 行政区 | `"嘉定区"` |

| `coordinates` | [float, float] | 高德 GCJ-02 经纬度 `[lng, lat]` | `[121.2530, 31.3304]` |

| `building_type` | string | 建筑形制与建筑形态 | `"高层板楼"` / `"电梯低密洋房"` |

| `noise_evaluation` | object | **多源立体交通噪音几何拓扑评估**（轨交高架/主干道/高速三维测算） | 见下文噪音规范 |

## 4. 户型档案模型（Layout Schema）

每个小区必须拆解出**标准两房**与**标准三房**，杜绝杂乱的流水账房源：

```json
{
  "category": "两房",                     // 必须为 "两房" 或 "三房"
  "title": "中信泰富一期 地铁口全明紧凑两居",
  "rooms": "2室2厅1厨1卫",
  "area": "76㎡",                        // 建筑面积
  "usable_area": "62㎡",                 // 套内实得面积
  "usable_rate": "81.6%",               // 实测得房率（重点展示字段）
  "price_wan": 312.0,                   // 参考总价（万元）
  "unit_price": 41052,                  // 单价（元/㎡）
  "orientation": "南",                  // 户型朝向
  "tags": ["嘉定新城站口", "首付友好", "得房率81.6%"],
  "floor_plan_local": "assets/floorplans/107116518245.jpg", // 本地化图片
  "pros": "距嘉定新城站步行仅3分钟，全明采光格局无暗间，总价在全大盘中最为亲民。",
  "cons": "一期梯户比为两梯四户，早晚高峰电梯偶有等待。"
}
```

## 4. 字段质量红线
1. **得房率红线**：`usable_rate` 必须依据公摊科学计算，高层板楼通常在 78%~83%，多层洋房通常在 84%~88%；
2. **交通具体化**：严禁写“交通便利”等套话，必须写清：
   - 目标站点与出入口（如“11号线嘉定新城站4号口”）；
   - 实际测算步行距离与用时（如“步行230米，耗时约3分钟”）；
3. **优缺点客观性**：`pros` 讲清空间得房亮点与生活动线，`cons` 必须诚实指出采光面宽、厨卫暗间、高架噪音或梯户比折旧问题。
