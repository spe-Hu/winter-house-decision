# 嘉定购房参考地图 — 系统架构与技术规范

## 1. 架构总览

本项目为轻量级、离线优先的个人买房辅助工具，基于纯前端架构运行，无构建步骤、无后端服务、无外部运行时依赖。

```
┌─────────────────────────────────────────────────────────────────┐
│                          用户界面层                              │
│  index.html (Leaflet 1.9.4 + 自定义暗黑主题 CSS + 响应式抽屉组件)  │
└────────────────┬───────────────────────────────┬────────────────┘
                 │ 动态渲染                      │ 静态加载
┌────────────────┴──────────────┐ ┌──────────────┴────────────────┐
│          地图底图层           │ │          本地数据层            │
│ 1. 高德官方矢量真彩图(style=7) │ │ 1. data/dataset.js (前端运行)  │
│ 2. 高德官方卫星影像组(style=6+8)│ │ 2. data/jiading_xiaoqu.json    │
│ (公开瓦片端点，免API Key)     │ │ 3. assets/floorplans/*.jpg   │
└───────────────────────────────┘ └───────────────────────────────┘
```

## 2. 坐标系统与渲染规范（核心准则）

### 2.1 统一坐标系：GCJ-02（火星坐标系）
- 项目底层数据（JSON/JS）存储格式严格为高德规范：`[经度 lng, 纬度 lat]`；
- 严禁在本地代码中随意混用 WGS-84（GPS 原始）或 BD-09（百度坐标）；
- 严禁盲目执行全量二次坐标平移，避免已对齐的 GCJ-02 坐标漂移。

### 2.2 Leaflet 视口转换与居中锚定
Leaflet 默认传参为 `[纬度 lat, 经度 lng]`，在渲染标记点时必须完成数组翻转：
```javascript
// 渲染标记
const marker = L.marker([c.coordinates[1], c.coordinates[0]], {
  icon: L.divIcon({
    className: 'custom-marker',
    iconSize: [48, 48],
    iconAnchor: [24, 24] // 必须严格中心锚定，禁止底部锚定导致视觉偏北
  })
});
```

### 2.3 底图双图层设计（免 Key 工业级瓦片）
- **高德官方真彩全要素矢量底图**（默认）：
  `https://wprd0{s}.is.autonavi.com/appmaptile?x={x}&y={y}&z={z}&lang=zh_cn&size=1&scl=1&style=7`
  特点：含嘉定最新路网、建筑轮廓、商圈注记、地铁站出入口注记。
- **高德官方真实航拍卫星影像组**：
  由遥感影像底图（`style=6`）与矢量路网注记透明图层（`style=8`）合成图层组，支持右上角控制器一键切换，用于核验小区真实楼栋间距与周边绿地河道水系。

## 3. 数据管道与自动化质量门禁架构

数据流遵循单向严格流动原则，交付前必须通过 6 步全流程自动化质量流水线：

```
[高德官方 POI 接口 (types=120300)] + [2026 官方学区图文] + [户型图真值图库]
                                      │
                                      ▼
                      [data/jiading_xiaoqu.json (唯一真相源)]
                                      │
         ┌────────────────────────────┴────────────────────────────┐
         │                                                         │
         ▼                                                         ▼
[scripts/align_school_ground_truth.py]           [scripts/spatial_noise_engine.py]
  (2026官方中小学双学区真值注入)                   (11号线高架/主干道/高速立体噪音拓扑)
         │                                                         │
         └────────────────────────────┬────────────────────────────┘
                                      ▼
                     [scripts/build_dataset.py (打包编译)]
                                      │
                                      ▼
                     [data/dataset.js (前端只读数据包)]
                                      │

                                      │
                                      ▼
                      [index.html (纯前端免构建交付)]
```

## 4. 空间拓扑与多模态真值保障架构

1. **坐标防漂移设计**：全量坐标必须经 `scripts/verify_all_phases.py` 调用高德官方接口比对，确保与高德官方底图标注文字 0 米误差；
2. **户型图房间数物理真值**：建立 `data/floorplan_catalog.json` 权威元数据，所有图片经 OCR 物理房间标尺比对，两房有且仅有 2 间卧室，三房必须有 3 间卧室（主卧、次卧、书房/客卧），两房三房绝对不可同图；
3. **多源立体交通噪音几何引擎**：建立 11 号线地上高架段、胜辛路主干道、S5 高速空间矢量折线，精确计算空间垂距与衰减，实施一票否决权；
4. **2026 官方学区权威真值库**：基于嘉定教育局 2026 官方文字版与 63 张全彩学区切片图（Apple Vision OCR），为全量小区注入小学+初中双学区档案与划片避坑指南。

## 5. 全球双通道网络部署架构

为彻底解决国内直连访问受阻痛点，系统构建了免翻墙直连与开源备份双通道：

1. **Cloudflare Pages 全球 CDN 加速（主推荐）**：
   - 地址：`https://winter-house-decision.pages.dev/`
   - 通过 Cloudflare Anycast 边缘网络分发静态页面与高清原图，亚太直连延迟极低，中国大陆地区免翻墙秒开；
   - 自动化部署入口：`./scripts/deploy_cloudflare.sh`。
2. **GitHub Pages（备用镜像通道）**：
   - 地址：`https://spe-hu.github.io/winter-house-decision/`
   - 托管于 GitHub 远程主仓库 `spe-Hu/winter-house-decision`，自动化流水线推送即触发构建。
3. **安全门禁认证机制**：
   - 采用前端加盐单向哈希算法（`calcSha256Hex(AUTH_SALT + pin)`），有效防御静态源码泄露，输入口令 `9802` 即可解密进入决策工作台。
